# CestIQ

Тренажер до теоретичного іспиту на водійські права в Словаччині (PWA).

- 1 416 офіційних питань (категорія B: 1 083), інтервальне повторення, прогноз CestIQ 0–100
- Мови пояснень: українська, словацька, англійська
- Працює офлайн, дані зберігаються на пристрої, є резервна копія (JSON)

Перебудова після змін: `python3 tools/build_cestiq.py && python3 tools/build_cestiq_pwa.py` (з батьківського проєкту).
